# ランキング 実装計画

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 自分の上位3件（ブラウザ保存）と、みんなのベスト10（Cloudflare Workers + D1）を記録・表示する。

**Architecture:** 名前・記録の判定と並べ方は `src/logic/ranking.js` にまとめ、ゲームと受付（Workers）の両方で読み込む。ゲームは `src/net/rankingApi.js` を通して受付と話し、失敗はすべて `null` で受けて「つうしんできません」を出す。受付は `server/` に置き、手元では `wrangler dev`（ローカル D1）で、本番は workers.dev で動かす。

**Tech Stack:** Phaser 3.90（ビルドなし ES modules）、自作テストランナー（Edge ヘッドレス）、Cloudflare Workers + D1（wrangler 4.158.0）、Node 24（確認スクリプト）

**Spec:** `docs/superpowers/specs/2026-11-09-ranking-design.md`

## Global Constraints

- 名前は1〜6文字（コードポイント数）。ひらがな・カタカナ・漢字・英数字（全角・半角）と長音「ー」だけ。前後の空白は除く
- 点数は `scorePoints`（records.js、変更しない）。順位は点数の高い順、同点は先に出した記録が上
- `MAX_COINS` はステージの `C` の数（77）、`MIN_TIME_MS = 45000`、`MAX_TIME_MS = 3600000`
- 送るのは `fullRun` のクリアだけ。通信は 5 秒で打ち切り、失敗は `null`
- 受付：`POST /scores`・`GET /scores`、本文 1KB まで（超えたら 413）、同じ `ip_hash` から 20 秒以内は 429、1 日たった `ip_hash` は空にする、返事に `ip_hash`・id・時刻を入れない（`at` は日本時間の日付 `YYYY-MM-DD`）
- SQL は必ず `prepare(...).bind(...)`。名前を HTML に入れない（`innerHTML` 禁止、`textContent` のみ）。受付はログに IP・本文を出さない
- CORS は `https://tshindo73.github.io`、`http://localhost:*`、`http://192.168.*.*:*` だけ
- `IP_SALT` は Workers のシークレット。`server/.wrangler/`・`server/.dev.vars`・`server/node_modules/` は `.gitignore`。`wrangler.toml` にアカウント ID を書かない
- 禁止語リストは入れない
- 新しい日本語の文字を canvas に出したら `tools/import-assets.py` でフォントを作り直す（入力: `..\入力\pixel-adventure-1\Free`、`..\入力\dotgothic16\DotGothic16-Regular.ttf`）
- テスト実行：`powershell -NoProfile -ExecutionPolicy Bypass -File tools/run-tests.ps1`（最後に `failed=0`）
- コミットの作成者は noreply アドレス（設定済み）。末尾に `Co-Authored-By: Claude Opus 5.5 <noreply@anthropic.com>`

## Review Focus

1. スマホの日本語入力で、変換を確定する Enter（`isComposing`）で名前が送られてしまう → 変換中の Enter は無視する（Task 5 の Playwright 確認）
2. タイトル画面で RANKING ボタンをタップすると、同時にゲームも始まってしまう（タイトルは指を離すとスタートする）→ ボタンの上ではスタートしない（Task 6 の Playwright 確認）
3. OK を素早く2回押して記録が2回送られる → 1回だけ送る（Task 5 の Playwright 確認で POST の回数を数える）
4. 受付が返事をしないまま止まる → 5 秒で「つうしんできません」になり、タイトルへ戻れる（Task 3 のテストと Task 5 の確認）
5. 同じ点数の記録が並んだときの順位（受付側）→ 先に出したほうが上（Task 4 の確認スクリプトで同点を入れて確かめる）

### Task 5: 名前入力とクリア画面

**Files:**
- Create: `src/ui/nameInput.js`
- Modify: `src/scenes/ClearScene.js`、`index.html`（名前入力の CSS）

**Interfaces:**
- Consumes: `normalizeName`・`NAME_MAX`（Task 1）、`loadTop3` `saveTop3` `loadName` `saveName`（Task 2）、`mergeTop`（Task 1）、`submitRun`（Task 3）
- Produces: `askName(scene, { initial = '', cancelLabel = 'おくらない' }) -> Promise<string | null>`（OK で正しい名前、取り消しで null）

名前入力は `#game` の上に `position: fixed` の箱を作り、DOM は `createElement` と `textContent` だけで組む。中身: 見出し「なまえ（6文字まで）」、`<input>`（`maxlength="12"`、`autocomplete="off"`、`enterkeyhint="done"`）、注意「みんなに公開されます。本名や連絡先は入れないでね」、間違いのとき「1〜6文字の ひらがな・カタカナ・漢字・英数字 にしてね」、ボタン「OK」と `cancelLabel`。開いている間は `scene.input.keyboard.enabled = false`、閉じたら戻して箱を消す。Enter は `event.isComposing` のときは無視。OK は一度押したら無効にする。

クリア画面（`fullRun` のとき）:
1. `const run = { timeMs: elapsedMs, coins, at: new Date().toISOString() }`、`mergeTop(loadTop3(), run, 3)` を保存。rank 1 は NEW!、2 は `2ND`、3 は `3RD`（NEW! と同じ桃色の札）、null は今の BEST の行（`list[0]`）
2. 名前 = `loadName()`、なければ `askName`。null なら送らない
