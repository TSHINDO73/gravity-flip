# 演出強化（ゲームの手触り）実装計画

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** ジャンプ・着地・反転・コイン・踏みつけ・ミス・ゴールに控えめな演出を入れる。当たり判定と操作感は変えない。

**Architecture:** Player を「非表示の物理の体」と「見た目用スプライト `view`」に分け、伸び縮みは `view` にだけかける。演出は `Effects` にまとめ、Player はシーンのイベント（`player-jumped` / `player-landed` / 既存の `gravity-flipped`）を出すだけにする。判定や倍率の計算は `fxRules.js` に置いてテストする。

**Tech Stack:** Phaser 3.90（`lib/phaser.min.js`、ビルドなし ES modules）、自作テストランナー（Edge ヘッドレス）

**Spec:** `docs/superpowers/specs/2026-10-27-game-feel-design.md`

## Global Constraints

- 当たり判定（Arcade の body の大きさと位置）を変えない。拡大率を変えるのは `view` だけ
- 新しい画像素材・外部ライブラリは使わない。粒のテクスチャは直径 4px の白い丸 `fx-dot` をプログラムで作る
- 演出の値は `src/objects/Effects.js` 冒頭の定数、判定の値は `src/logic/fxRules.js` の定数に置く
- 演出の深さは 50（HUD 100、タッチボタン 110 より奥）
- `prefers-reduced-motion: reduce` のときは揺れの強さだけ 0
- テスト実行：`powershell -NoProfile -ExecutionPolicy Bypass -File tools/run-tests.ps1`（最後に `failed=0`）

## Review Focus

1. ミス中（`Player.update` が呼ばれない間）の点滅と位置：`view` が体に追従し、点滅も見えること（Task 2 で POST_UPDATE で写す。Task 2 Step 4 で確認）
2. やり直し・ステージ切り替え後：前のシーンの `view` や POST_UPDATE の登録が残らず、二重表示やエラーが出ないこと（Task 2 で SHUTDOWN 時に登録を外す）
3. リスポーン直後の着地：小さな勢いの着地で砂ぼこりが出ないこと（Task 1 の `shouldDust` 境界テスト）
4. 上向き移動中に天井へぶつかった場合など、足元へ向かっていない「着地」で砂ぼこりを出さないこと（Task 1 テスト `landingImpact: 足元から離れる向きは負`）
5. 伸び縮みのトゥイーンが重なったとき（ジャンプ直後の着地など）：倍率が 1 に戻らず固まらないこと（Task 3 で新しいトゥイーンの前に既存を止め、必ず 1 へ戻す）

### Task 1: 演出の計算部分（fxRules.js）

**Files:**

- Test: `tests/fxRules.test.js`
- Modify: `tests/index.html`（`import './fxRules.test.js';` を `inputRules.test.js` の次に追加）

**Interfaces:**
- Produces:
  - `LAND_DUST_MIN_SPEED = 350`
  - `landingImpact(lastVy: number, gravityDir: 1 | -1) -> number`：足元へ向かう速さ（`lastVy * gravityDir`）。足元から離れる向きなら負
  - `shouldDust(impact: number) -> boolean`：`impact >= LAND_DUST_MIN_SPEED`
  - `squashScale(kind: 'jump' | 'land') -> { x: number, y: number }`：jump は `{ x: 0.85, y: 1.15 }`、land は `{ x: 1.2, y: 0.8 }`
  - `shakeIntensity(base: number, reducedMotion: boolean) -> number`

- [ ] **Step 1: 失敗するテストを書く**

```js

import { LAND_DUST_MIN_SPEED, landingImpact, shouldDust, squashScale, shakeIntensity } from '../src/logic/fxRules.js';

test('landingImpact: 重力の向きに合わせて足元へ向かう速さ', () => {
  assertEqual(landingImpact(500, 1), 500);
  assertEqual(landingImpact(-500, -1), 500);
});

test('landingImpact: 足元から離れる向きは負', () => {
  assertEqual(landingImpact(-500, 1), -500);
});

test('shouldDust: 境界は 350', () => {
  assertEqual(LAND_DUST_MIN_SPEED, 350);
  assertEqual(shouldDust(349), false);
  assertEqual(shouldDust(350), true);
  assertEqual(shouldDust(landingImpact(-400, -1)), true);
  assertEqual(shouldDust(landingImpact(-400, 1)), false);
});

test('squashScale: ジャンプと着地', () => {
  assertEqual(squashScale('jump'), { x: 0.85, y: 1.15 });
  assertEqual(squashScale('land'), { x: 1.2, y: 0.8 });

test('shakeIntensity: 視差効果を減らす設定なら 0', () => {
  assertEqual(shakeIntensity(0.006, true), 0);
  assertEqual(shakeIntensity(0.006, false), 0.006);
});
```

### Task 2: 見た目と当たり判定を分ける（見た目は変えない）

**Files:**
- Modify: `src/objects/Player.js`

**Interfaces:**
- Produces:
  - `Player.view: Phaser.GameObjects.Sprite`（見た目。深さは Player と同じ既定値）
  - `Player.squash: { x: number, y: number }`（初期値 `{ x: 1, y: 1 }`。Effects がトゥイーンする）

- [ ] **Step 1: `view` と同期処理を追加**

- コンストラクタで `scene.add.sprite(x, y, IMG.chars, FRAMES.player)` を `this.view` として作り、Player 自身は `setVisible(false)`。
- `syncView()`：`view` に Player の `x` `y` `frame.name` `flipX` `flipY` `alpha` と色（`isTinted` なら `tintTopLeft` を `setTint`、そうでなければ `clearTint`）を写し、`setScale(SCALE * squash.x, SCALE * squash.y)`。
- `scene.events.on(Phaser.Scenes.Events.POST_UPDATE, this.syncView, this)` で毎フレーム呼ぶ。`scene.events.once(SHUTDOWN, ...)` で外す。
- 歩きアニメは Player の `anims` のままでよい（表示フレームを写すため）。

### Task 3: ジャンプ・着地・反転の演出

**Files:**
- Create: `src/objects/Effects.js`
- Modify: `src/objects/Player.js`（イベント発行と `lastVy`）
- Modify: `src/scenes/GameScene.js`（Effects の作成とイベントの受け取り）

**Interfaces:**
- Consumes: `landingImpact`、`shouldDust`、`squashScale`、`shakeIntensity`（Task 1）、`Player.view`、`Player.squash`（Task 2）
- Produces:
  - `class Effects { constructor(scene, { player, hud }); jump(); land(impact: number); flip(); coin(x, y); stomp(x, y); death(x, y); goal(x, y) }`（`coin` 以降は Task 4）
  - シーンイベント `'player-jumped'`（引数なし）、`'player-landed'`（引数 `impact: number`）

- [ ] **Step 1: Player からイベントを出す**

- ジャンプした直後（`setVelocityY(jumpVelocityY(dir))` の後）に `this.scene.events.emit('player-jumped')`。
- 接地判定で「前フレームは空中・今フレームは接地」のときに `this.scene.events.emit('player-landed', landingImpact(this.lastVy, dir))`。
- `update` の最後で `this.lastVy = body.velocity.y`。`respawn` で `lastVy = 0`。

- [ ] **Step 2: `src/objects/Effects.js`（jump / land / flip）を実装**

- 冒頭に定数をまとめる（spec の表の値：伸び縮み 120ms、砂ぼこり 4 個・300ms・灰白色、反転の輪 半径 10→40・不透明度 0.6→0・250ms、深さ 50）。
- コンストラクタで、テクスチャ `fx-dot` が無ければ `scene.make.graphics` で直径 4px の白い丸を描いて `generateTexture` する。`reducedMotion` を `matchMedia('(prefers-reduced-motion: reduce)')` で読む。
- 伸び縮み：`squashScale(kind)` の値を `player.squash` に即座に入れ、`scene.tweens.add({ targets: player.squash, x: 1, y: 1, duration: 120 })` で戻す。新しいトゥイーンを始める前に `scene.tweens.killTweensOf(player.squash)` する（Review Focus 5）。
- `land(impact)`：伸び縮みは毎回。`shouldDust(impact)` が真のときだけ、足元（`player.feetY`）の左右に粒を出す。粒は床から離れる向き（`-gravityDir` 方向）に少し跳ね、重力の向きに合わせて落ちる。
- 粒は `scene.add.particles(x, y, 'fx-dot', { ..., emitting: false })` を作って `explode(count)` し、寿命の最大値の後に `destroy()` する。
- `flip()`：`player` の位置に白い円（`scene.add.circle`、塗りなし・線のみでも可）を出し、半径と不透明度をトゥイーンして消す。

- [ ] **Step 3: GameScene で Effects を作り、イベントにつなぐ**

- Player と HUD を作った後に `this.effects = new Effects(this, { player: this.player, hud: this.hud })`。
- `this.events.on('player-jumped', ...)`、`'player-landed'`、`'gravity-flipped'` を受けて `jump` / `land` / `flip` を呼ぶ。既存の `onFlip` と同様に SHUTDOWN で外す。

- [ ] **Step 4: テストを実行**

Expected: `SUMMARY passed=55 failed=0`

- [ ] **Step 5: Playwright で確認**

PC 1000×600、`?stage=1`。ジャンプ直後（縦に伸びている）、高い所からの着地直後（潰れて砂ぼこり）、反転直後（白い輪）を撮影。`?debug=1` で着地の潰れ中も当たり判定の枠の大きさが変わらないこと。コンソールにエラーが無いこと。

- [ ] **Step 6: コミット**

```bash
git add src/objects/Effects.js src/objects/Player.js src/scenes/GameScene.js
git commit -m "feat: jump, landing and flip effects"
```

### Task 4: コイン・踏みつけ・ミス・ゴールの演出

**Files:**
- Modify: `src/objects/Effects.js`
- Modify: `src/scenes/GameScene.js`（コイン取得、`onTouchEnemy` の踏みつけ、`killPlayer`、`onGoal`）

**Interfaces:**
- Consumes: Task 3 の `Effects`、`shakeIntensity`

- [ ] **Step 1: Effects に coin / stomp / death / goal を実装**

spec の表の値どおり：
- `coin(x, y)`：黄色い粒 6 個・300ms。`hud` を 1.0 → 1.1 → 1.0（100ms、yoyo）。HUD のトゥイーンは開始前に既存を止め、拡大率を 1 に戻してから始める。
- `stomp(x, y)`：揺れ 80ms・強さ `shakeIntensity(0.004, reducedMotion)`、白い粒 6 個・300ms。
- `death(x, y)`：揺れ 150ms・強さ `shakeIntensity(0.006, reducedMotion)`、粒 10 個・400ms。
- `goal(x, y)`：色とりどりの粒 20 個が上へ・600ms。揺れなし。
- 揺れの強さが 0 のときは `cameras.main.shake` を呼ばない。

- [ ] **Step 2: GameScene から呼ぶ**

コインを消す直前の位置で `coin`、踏みつけ成功時に敵の位置で `stomp`、`killPlayer` で Player の位置で `death`、`onGoal` でゴールの位置で `goal`。
