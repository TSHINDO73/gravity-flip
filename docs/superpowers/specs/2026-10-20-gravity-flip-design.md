# Gravity Flip 設計書

作成日: 2026-10-20

## 1. 目的と前提

- 目的: 学習・趣味としてのゲーム制作。ただし少人数に見せる可能性があるため、URL共有で遊べて見栄えも一定水準にする。
- 内容: マリオ風の2D横スクロールアクションに「重力の上下反転」を加えたプロトタイプ。
- 規模: 3ステージ（チュートリアル → 応用 → 難しめ）＋タイトル画面＋クリア画面。
- 対象環境: PCブラウザ、キーボード操作のみ。スマホ対応は対象外。
- 成功基準:
  - 3ステージを通してクリアまで遊べる。
  - 各ステージに「空中1回反転」を使わないと突破できない場面が少なくとも1つある。

## 2. 技術構成

- Phaser 3（Arcade Physics）を使用。`lib/phaser.min.js` として同梱する（CDN非依存）。
- ビルドツールは使わない（Node.js 未導入のため）。ES Modules を `index.html` から直接読み込む。
- ローカル確認: `python -m http.server` でフォルダを配信し、ブラウザで開く。
- 公開: GitHub Pages にフォルダをそのまま配置する。公開操作の前にユーザーへ確認する。
- 画面サイズ: 960×540。1マス36ピクセル（Kenney の18ピクセル素材を2倍表示）。
- git で管理する。

## 3. フォルダ構成

```
gravity-flip/
  index.html            入口。Phaser と src/main.js を読み込む
  lib/phaser.min.js     Phaser 3 本体
  src/
    main.js             ゲーム設定（画面サイズ、物理、シーン一覧）
    scenes/
      BootScene.js      画像・音の読み込み
      TitleScene.js     タイトル画面
      GameScene.js      ステージ本編。配置データから物を置き、当たり判定をつなぐ
      ClearScene.js     全クリア画面（コイン枚数・タイム表示）
    objects/
      Player.js         移動・ジャンプ・重力反転
      Enemy.js          歩く敵
    logic/
      flipRules.js      重力反転の可否判定（Phaser非依存の純粋関数）
    levels/
      levels.js         3ステージ分の文字マップ
      parseLevel.js     文字マップ → 配置データへの変換（Phaser非依存）
  assets/               Kenney の画像・効果音（CC0）
  tests/
    index.html          ブラウザで開くと自動テスト結果を表示
    *.test.js           parseLevel・flipRules のテスト
  CREDITS.md            素材の出典
```

各ユニットの責務:
- `Player.js`: プレイヤーの操作と状態。反転可否は `flipRules.js` に問い合わせる。
- `flipRules.js`: 「今の状態で反転できるか」「着地で回復するか」を判定する純粋関数のみ。
- `parseLevel.js`: 文字列配列を受け取り、タイル・オブジェクトの座標一覧を返す。不正入力はエラーを投げる。
- `GameScene.js`: 上記の結果を使って画面を組み立てる係。ゲームルールのロジックは持たない。

## 4. プレイヤーと重力反転

### 操作

| キー | 動作 |
|---|---|
| ← → | 移動 |
| Z / スペース | ジャンプ |
| X / ↑ | 重力反転 |
| R | ステージをやり直す |

### 重力反転のルール

- 重力の向きは「下」か「上」の2状態。
- 反転するとプレイヤーの絵も上下反転し、「足元」は重力の向き側になる。
- 接地中: 何度でも反転できる。
- 空中: 1回だけ反転できる。「足元」側に着地すると回復する。
- 空中反転が使用済みのときは、キャラを少し暗くして見分けられるようにする。
- 反転直後は縦方向の速度を0にリセットする。
- ジャンプは常に「足元から離れる方向」に飛ぶ。

### 操作感

- 可変ジャンプ: 長押しで高く、すぐ離すと低く（離した時点で上昇速度を減らす）。
- コヨーテタイム: 足場を離れて0.1秒以内はジャンプ可能。
- 先行入力: 着地前0.1秒以内に押したジャンプは着地時に実行。

### 死亡と復活

- 死亡条件: トゲに触れる／敵に「足元」以外から当たる／ステージの上下の外へ出る。
- 復活: ステージのスタート位置、または通過済みの中間旗から再開。
- 残機なし（何度でも挑戦可能）。再開時は重力を「下」、空中反転を回復済みに戻す。
- 取得済みコインは死亡しても保持する。

## 5. ステージ

### 文字マップの記法

| 文字 | 意味 |
|---|---|
| `#` | ブロック |
| `^` | トゲ（床に置く、上向き） |
| `v` | トゲ（天井に付ける、下向き） |
| `E` | 歩く敵 |
| `C` | コイン |
| `F` | 中間旗 |
| `P` | スタート位置（各ステージにちょうど1つ） |
| `G` | ゴール旗（各ステージにちょうど1つ） |
| `.` | 空白 |

- ステージは上下が閉じた通路型を基本とする。上下とも抜けている場所は穴であり、外へ出ると死亡。
- カメラは横方向にプレイヤーを追う。縦はステージの高さを画面内に収める（縦スクロールなし）。ステージの高さは最大15行（540÷36）とする。

### 敵

- 左右に歩き、壁または足場の端で向きを変える。
- 敵も重力の影響を受け、プレイヤーが反転すると全ての敵も同時に反転する。
- プレイヤーが自分の「足元」側から敵に当たると敵を倒せる（踏みつけ）。それ以外の接触はプレイヤーの死亡。

### 3ステージの狙い

1. チュートリアル: 反転の基本。天井の通路を進む、トゲを反転で避ける。
2. 応用: 空中1回反転を使う長い穴、敵を一緒に反転させて道を開ける。
3. 難しめ: ジャンプ・反転・敵を組み合わせた連続アクション。

### 得点とクリア

- コインは得点のみ。
- ゴール旗に触れると次のステージへ。ステージ3クリアでクリア画面に移り、合計コイン枚数と合計タイムを表示。

## 6. 画面遷移

タイトル → ステージ1 → ステージ2 → ステージ3 → クリア画面 → （キー入力で）タイトル

## 7. 素材

- 画像: Kenney「Pixel Platformer」（CC0）。
- 効果音: Kenney の効果音パック（CC0）。ジャンプ・反転・コイン・死亡・クリアの5種類。
- 必要なファイルだけ `assets/` にコピーし、`CREDITS.md` に出典を記載する。

## 8. エラー処理

- `parseLevel` は以下を検出してエラーを投げる。メッセージには「ステージ番号・行・列」を含める。
  - 記法にない文字
  - `P` または `G` が無い、または複数ある
  - 行の長さが揃っていない
  - 行数が15を超える
- `GameScene` はエラーを受けたら画面にメッセージを表示して停止する。
- 素材の読み込み失敗時はファイル名をコンソールに出力する。

## 9. テスト

- 自動テスト: `tests/index.html` をブラウザで開くと結果を表示する簡易テストランナー（外部ライブラリなし）。
  - `parseLevel`: 正常な変換、各エラーの検出。
  - `flipRules`: 接地中は反転可、空中は1回のみ可、着地で回復、死亡・再開で回復。
- 手動確認: 3ステージをクリアまで通しプレイし、各ステージで空中1回反転が必要な場面があることを確認する。
