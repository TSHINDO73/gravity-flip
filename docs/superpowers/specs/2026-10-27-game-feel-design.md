# 演出強化（ゲームの手触り）設計

日付: 2026-10-27

## 目的

ジャンプ・着地・反転・コイン・踏みつけ・ミス・ゴールに控えめな演出を入れて、触っていて気持ちのいい手触りにする。重力反転を何度も繰り返すゲームなので、プレイの邪魔をせず、目が疲れない強さにとどめる。当たり判定と操作感は今と変えない。

## 決めたこと

- 方向性は「控えめ・上品」。演出は小さく短くする
- 対象はジャンプ・着地、重力反転、コイン取得、踏みつけ・ミス・ゴールのすべて
- Phaser に元からある機能（トゥイーン、パーティクル、カメラシェイク）だけで作る。新しい画像素材と外部ライブラリは使わない
- 演出は `Effects` にまとめ、強さや数は1か所の定数で調整できるようにする
- OS の「視差効果を減らす」設定（`prefers-reduced-motion: reduce`）がオンなら、画面の揺れだけを止める

## 部品の構成

```
Player ─(player-jumped / player-landed / gravity-flipped)─┐
GameScene ─(コイン・踏みつけ・ミス・ゴール)─────────────────┼─→ Effects ─→ 粒・揺れ・伸び縮み
```

### 新規

| ファイル | 役割 |
|---|---|
| `src/logic/fxRules.js` | 画面に依存しない計算。着地の勢いから砂ぼこりを出すかの判定、伸び縮みの倍率、揺れの強さ（視差効果を減らす設定の反映） |
| `src/objects/Effects.js` | 演出係。`jump` `land` `flip` `coin` `stomp` `death` `goal` を持つ。値はファイル冒頭の定数にまとめる |

### 変更

| ファイル | 内容 |
|---|---|
| `src/objects/Player.js` | 見た目と当たり判定を分ける（下記）。跳んだ瞬間に `player-jumped`、着地した瞬間に `player-landed`（着地の勢いつき）をシーンのイベントとして出す。反転は既存の `gravity-flipped` を使う |
| `src/scenes/GameScene.js` | Effects を作り、Player のイベントと、コイン・踏みつけ・ミス・ゴールの処理から呼ぶ |

### 見た目と当たり判定を分ける

Phaser の Arcade Physics では、スプライトの拡大率を変えると当たり判定の大きさも変わる。伸び縮みで判定が変わると、床へのめり込みやトゲ判定のずれが起きる。

- Player（物理の体）は非表示にし、当たり判定・移動・アニメの状態はこれまでどおり Player が持つ
- 見た目用のスプライト（`Player.view`）を別に作り、毎フレーム、Player の位置・表示フレーム・左右反転・上下反転・色（tint）・不透明度を写す
- 写す処理は、物理の計算が終わった後（シーンの `POST_UPDATE`）に行う。死亡中など `Player.update` が呼ばれないフレームでも写す
- 伸び縮みは `view` の拡大率にだけかける。基準は `SCALE`（2）で、伸び縮みは倍率を掛ける
- 既存のミス時の点滅（Player の不透明度のトゥイーン）は、不透明度を写すことでそのまま `view` に反映される

## 演出の詳細

値はすべて `Effects.js` 冒頭の定数。

| 場面 | 演出 | 値 |
|---|---|---|
| ジャンプ | `view` が縦に伸びて戻る | 横 0.85 倍・縦 1.15 倍、0.12 秒で戻る |
| 着地 | `view` が横に潰れて戻る。足元の左右に砂ぼこり | 横 1.2 倍・縦 0.8 倍、0.12 秒で戻る。砂ぼこりは灰白色の粒4個、0.3 秒。着地の勢いが毎秒 350px 以上のときだけ出す |
| 重力反転 | キャラを中心に白い輪が広がって消える | 半径 10px → 40px、不透明度 0.6 → 0、0.25 秒。揺れなし |
| コイン | 取った位置に黄色い粒。HUD が少し弾む | 粒6個、0.3 秒。HUD は 1.0 → 1.1 倍 → 1.0、0.1 秒 |
| 踏みつけ | 画面の揺れ＋白い粒 | 揺れ 0.08 秒・強さ 0.004、粒6個、0.3 秒 |
| ミス | 画面の揺れ＋粒（点滅はそのまま） | 揺れ 0.15 秒・強さ 0.006、粒10個、0.4 秒 |
| ゴール | 色とりどりの粒が上へ舞う | 粒20個、0.6 秒。揺れなし |

### 着地の勢い

- `Player.update` の最後に、そのフレームの縦速度を `lastVy` として覚える
- 着地したフレーム（前フレームは空中で、今フレームは接地）に、`lastVy × 重力の向き`（足元へ向かう速さ、正の値）を着地の勢いとして渡す
- 衝突でそのフレームの速度は 0 になっているため、前フレームの値を使う

### 重力が上向きのとき

- 砂ぼこりは足元（天井側）から出し、床から離れる向き（下向き）に散らす
- 伸び縮みは拡大率で表すので、上下反転していても同じ倍率でよい

### 粒の作り方

- 直径 4px の白い丸のテクスチャ（キー `fx-dot`）を、最初に1回だけプログラムで作る
- 場面ごとに色（tint）を付けて使う。パーティクルは一度だけ放出（explode）し、寿命が来たら消える

### 重なり順

- 演出は、ステージより手前、HUD（深さ 100）とタッチボタン（110）より奥（深さ 50）に描く
- 画面の揺れは、HUD とタッチボタンもわずかに揺らす（0.15 秒以下なので許容する）

### 視差効果を減らす設定

- `window.matchMedia('(prefers-reduced-motion: reduce)').matches` が真なら、揺れの強さを 0 にする
- 粒と伸び縮みはそのまま出す

## テスト

### 自動テスト（`tests/fxRules.test.js`）

- 砂ぼこりの判定：勢いが 349 では出さない、350 では出す、重力が上向きでも同じ判定になる（`lastVy` と重力の向きから求めた勢いで判定する）
- 伸び縮みの倍率：ジャンプは (0.85, 1.15)、着地は (1.2, 0.8)
- 揺れの強さ：視差効果を減らす設定がオンなら 0、オフなら指定の値

### 当たり判定が変わらないことの確認

- `?debug=1` で当たり判定の枠を表示し、着地の伸び縮みの最中も枠の大きさが変わらないことを、Playwright の画像で確認する
- 既存の自動テストがすべて通る

### 見た目の確認（Playwright）

- ジャンプ・着地・反転・コイン・ミスの瞬間を撮影し、演出が出ていて、キャラが消えたりずれたりしていないこと
- PC とスマホ表示の両方で、コンソールにエラーが出ないこと

### ユーザーによる確認（PC と Android）

1. 演出がうるさすぎないか、物足りなくないか
2. 操作感（ジャンプの高さ、反転のタイミング、トゲや敵の判定）が今までと変わっていないか
3. スマホで重くなっていないか
4. 3ステージを通しでクリアできるか

感想に応じて `Effects.js` の定数を調整する。

## 対象外

- 新しい効果音や BGM
- 演出のオン・オフ設定画面
- 敵の見た目の伸び縮み（敵の踏みつけ演出は既存のまま）
